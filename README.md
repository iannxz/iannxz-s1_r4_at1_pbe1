# Node.js Express HTTP Routing Labs

Repositório com exercícios backend desenvolvidos em Node.js e Express, organizados por branches, com foco na criação de servidores HTTP, definição de rotas, uso de parâmetros na URL, query params, validação de entradas e retorno de respostas HTTP.

O projeto foi desenvolvido como prática de fundamentos de backend, explorando diferentes formas de estruturar endpoints e manipular dados recebidos por requisições HTTP.

## Tecnologias utilizadas

- Node.js
- Express.js
- JavaScript
- Nodemon

## Estrutura do repositório

O repositório está dividido em branches, onde cada branch representa um exercício independente.

| Branch | Descrição |
|---|---|
| `exercicio-01` | API de calculadora utilizando route params para operações de soma, subtração, multiplicação e divisão. |
| `exercicio-02` | API de calculadora utilizando query params para receber operação e valores numéricos. |
| `exercicio-03` | API de operação dinâmica, utilizando route params para definir o tipo de operação e query params para os valores. |
| `exercicio-04` | API para verificação de ano bissexto com base no valor informado pela rota. |
| `exercicio-05` | API de saudação dinâmica com base no nome informado na rota e no horário enviado por query parameter. |

## Conceitos praticados

- Criação de servidores HTTP com Express
- Definição de rotas GET
- Uso de route params
- Uso de query params
- Validação de parâmetros
- Tratamento de erros
- Respostas em texto e JSON
- Organização de exercícios em branches
- Tratamento de rotas inexistentes com erro 404
